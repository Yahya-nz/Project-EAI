# Inventory Service

Mengelola produk, stok, dan stock movement dalam database SQLite terpisah.

Port: `3002`. Dokumentasi interaktif: `http://localhost:3002/api-docs`.

Endpoint utama: `GET /products`, `GET /products/{id}`, `POST /stock/reduce`, `GET /stock-movements`, `GET /health`.

Lihat [panduan utama](../README.md) dan [hasil pengujian](../docs/hasil-pengujian.md).
